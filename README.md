# 名著改編誌 Classics Remixed

介紹世界經典名著，並整理每部作品至今的電影、影集、動畫、舞台、網路影音與惡搞改編版本，以及即將推出的新作。

目前收錄《羅密歐與茱麗葉》《傲慢與偏見》《科學怪人》《悲慘世界》四部作品，39 筆改編、6 種跨作品的改編手法、8 項即將推出。其中《悲慘世界》是依照 CLAUDE.md 的 Ingest 流程新增的第四本書，用來驗證這套規則能延續下去。

## 專案架構：LLM Wiki

本專案參考 Andrej Karpathy 提出的 LLM Wiki 模式，分成三層：

| 層 | 位置 | 說明 |
|---|---|---|
| 原始資料 | `raw/` | AI 查證時留下的來源紀錄，寫入後不再修改 |
| 知識頁 | `wiki/` | 作品頁、改編手法頁、索引 `index.md`、日誌 `log.md`，由 AI 維護並以 `[[連結]]` 互相串連 |
| 規則 | `CLAUDE.md` | 告訴 AI 這個 wiki 怎麼組織、怎麼收錄、怎麼健檢 |

`scripts/build.py` 讀取 wiki、檢查規則，再產生網頁。改編手法頁的例子清單由作品頁的標籤自動彙整，收錄的作品越多，跨作品的比較就越豐富。

## 怎麼使用

| 想做的事 | 對 AI 說 |
|---|---|
| 收錄新名著 | 「請先讀 CLAUDE.md，然後新增《小婦人》。」 |
| 問問題 | 「哪些改編讓配角變成主角？」 |
| 健檢 | 「健檢一下。」（AI 會執行 `python3 scripts/build.py --lint`） |

## 本機預覽

```bash
pip install pyyaml markdown
python3 scripts/build.py
```

再用瀏覽器開啟 `index.html` 即可。
